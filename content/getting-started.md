# Getting Started

Welcome to our getting started guide! This page will help you get up and running quickly.

## Prerequisites

Before you begin, ensure you have:
- Node.js 16 or later installed
- A code editor of your choice
- Basic knowledge of JavaScript/TypeScript

## Installation

1. Create a new project:

```bash
# Create a new directory for your project
mkdir ~/projects/my-new-project
cd ~/projects/my-new-project

# Initialize a new pnpm project
pnpm init

# Initialize a new git repository
git init

# Install Nuxt Content module
pnpm add @nuxt/content
```

::code-block{lang="javascript" code="console.log('ok')"}
::
